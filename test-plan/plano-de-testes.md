# Plano de Testes — E-commerce

## 1. Objetivo

Validar as principais funcionalidades da aplicação de e-commerce, identificando possíveis falhas que possam afetar a experiência do usuário e o processo de compra.

## 2. Escopo dos Testes

Serão testadas as seguintes funcionalidades:

- Login
- Visualização de produtos
- Ordenação de produtos
- Adição de produtos ao carrinho
- Remoção de produtos do carrinho
- Checkout
- Preenchimento dos dados do cliente
- Finalização da compra
- Logout

## 3. Tipos de Teste

- Testes funcionais
- Testes positivos
- Testes negativos
- Testes de validação
- Testes de regressão

## 4. Ambiente de Testes

**Aplicação:** SauceDemo

**URL:** https://www.saucedemo.com/

**Navegador:** Google Chrome

**Sistema operacional:** Windows

## 5. Critérios de Entrada

Os testes serão iniciados quando:

- A aplicação estiver acessível.
- O ambiente estiver disponível.
- As credenciais de teste estiverem disponíveis.

## 6. Critérios de Saída

Os testes serão considerados concluídos quando:

- Todos os casos de teste planejados forem executados.
- Os resultados forem registrados.
- Os bugs encontrados forem documentados.
- O relatório final de testes for elaborado.

## 7. Riscos

Possíveis riscos durante os testes:

- Indisponibilidade da aplicação.
- Falhas que impeçam a execução de outros testes.
- Comportamentos inesperados durante o processo de checkout.

## 8. Resultado Esperado

Ao final dos testes, será possível avaliar a qualidade das principais funcionalidades da aplicação e identificar possíveis defeitos que necessitem de correção.
